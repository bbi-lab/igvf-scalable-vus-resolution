# Data Prerequisites — License and Citation Manifest

This document accompanies the "Data prerequisites for 'A scalable approach
to resolving variants of uncertain significance'" Zenodo deposit (the
updated version of Zenodo record 18637474). It catalogs every file in that
deposit's origin, license, and required citation, so downstream users know
exactly what they can and can't do with each one.

- **Source code:** [bbi-lab/igvf-scalable-vus-resolution](https://github.com/bbi-lab/igvf-scalable-vus-resolution)
- **Preprint:** *"A scalable approach to resolving variants of uncertain
  significance,"* bioRxiv (2026).
  https://www.biorxiv.org/content/10.64898/2026.02.14.705848

**Record-level license:** CC BY 4.0, matching this project's other Zenodo
records. That license covers this project's own original content. Two
files are explicit exceptions, called out below and in the record's own
description — do not assume CC BY 4.0 applies to everything in the
archive.

**Where each file goes:** take a filename in this deposit, replace every
`__` with `/`, and that's the path it occupies under `data/input/` in a
checkout of the repository above -- e.g. `predictors__revel_hg38.tsv.gz`
goes at `data/input/predictors/revel_hg38.tsv.gz`. (Zenodo's legacy upload
API doesn't accept a literal `/` in a filename, hence `__` standing in for
the path separator.) The one exception is
`mave_calibration__excalibr__json.zip`, which isn't a single file: unzip
its contents into `data/input/mave_calibration/excalibr/json/` (one file
per MAVE dataset). This document itself (`LICENSE_AND_CITATIONS.md` in the
deposit) is reference documentation, not a pipeline input.
